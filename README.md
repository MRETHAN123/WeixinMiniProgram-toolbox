# 智汇工具箱

一个基于原生微信小程序开发的轻量生活与实用工具集合。项目无需安装第三方依赖，使用微信开发者工具即可直接运行。

## 功能

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 工具 | BMI 计算 | 根据身高和体重计算 BMI，并给出健康状态与建议 |
| 工具 | 房贷计算 | 按等额本息方式估算月供、总利息和还款总额 |
| 工具 | 单位换算 | 支持长度、温度、重量、体积和速度换算 |
| 工具 | 计时器 | 包含秒表和倒计时 |
| 工具 | 放大镜 | 调用设备后置摄像头，支持缩放和补光灯 |
| 工具 | 大屏时钟 | 显示当前时间、日期和星期，并保持屏幕常亮 |
| 生活 | 待办清单 | 创建带目标日期的任务并计算剩余天数 |
| 生活 | 心情日记 | 记录心情、标题和日记内容 |
| 我的 | 数据概览 | 展示待办和日记数量，并支持清除本地缓存 |

## 技术栈

- 微信小程序原生框架
- JavaScript
- WXML
- WXSS
- 微信本地存储 API

项目不依赖 npm 包、云开发或自建后端服务。

## 本地运行

### 环境要求

- 已安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 微信开发者工具基础库版本 `3.15.2` 或更高

### 启动步骤

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 将项目目录选为本仓库根目录。
4. 使用测试号运行，或在本地将自己的小程序 AppID 填入项目配置。
5. 点击“编译”即可在模拟器中查看。

> `project.private.config.json` 保存开发者的本地工具配置，不纳入版本控制。首次导入后，微信开发者工具会自动生成该文件。

## 数据说明

- 待办、日记和访问日志保存在微信小程序的本地存储中。
- 清除微信开发者工具缓存或点击“我的 > 清除数据缓存”会删除本地数据。
- 项目当前没有服务端，不会同步或上传用户内容。

## 发布前检查

- 首页和生活页使用了外部网络图片。正式发布前，请在小程序管理后台配置相应的 `downloadFile` 合法域名，或将这些图片改为本地资源。
- 放大镜功能需要摄像头权限，请在小程序后台完善隐私保护指引并声明摄像头用途。
- 房贷和 BMI 等计算结果仅供日常参考，不应作为金融、医疗或其他专业决策依据。
- 上传前请将 `project.config.json` 中的 `appid` 改为实际的小程序 AppID，避免继续使用测试 AppID。

## 已知事项

- `pages/logs`、`pages/tools/bigtext` 和 `components/result-card` 是暂未启用的预留文件，不影响现有功能。
- 放大镜页面的补光灯状态显示判断与 JavaScript 中的状态值尚未完全统一，后续可修复显示文案。
- 项目暂未提供自动化测试，提交前建议在微信开发者工具和真机上分别验证摄像头、震动、剪贴板和本地存储功能。
